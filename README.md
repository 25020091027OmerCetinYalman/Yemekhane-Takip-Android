# Yemekhane-Takip-Android
📱 Kampüs Yaşamı - Yemekhane Otomasyon Sistemi
Bu proje, Kahramanmaraş İstiklal Üniversitesi Yazılım Mühendisliği bölümü kapsamında geliştirilen, öğrencilerin kampüs içindeki yemekhane süreçlerini takip etmesini kolaylaştırmayı amaçlayan bir Android mobil uygulamadır.

🛠 Kullanılan Teknolojiler
Dil: Java

Platform: Android Studio

Arayüz: XML (Modern Design & Glassmorphism Effects)

Veritabanı: SQLite (Yerel veri yönetimi için)
